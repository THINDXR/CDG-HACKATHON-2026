# RoadWarn — เว็บแอปเตือนภัยบนท้องถนน

เว็บแอปแจ้งเตือนภัยบนถนนแบบเรียลไทม์ พร้อมแผนที่ 3 มิติที่ให้ความรู้สึกใกล้เคียง Apple Maps
(มุมกล้องเอียง อาคารสามมิติ ภูมิประเทศ และท้องฟ้าไล่เฉด) ทำงานเป็นเว็บสแตติกล้วน
ไม่ต้องมี backend และ **ไม่ต้องใช้ API key ใด ๆ**

## วิธีรัน

ต้องเสิร์ฟผ่าน HTTP server ตัวใดก็ได้ เช่น

```bash
python3 -m http.server 8080
# เปิด http://localhost:8080
```

บน Windows ที่ไม่มี Python/Node ใช้ตัวเสิร์ฟที่มากับ PowerShell ได้

```powershell
powershell -ExecutionPolicy Bypass -File tools/serve.ps1
```

ต้องเสิร์ฟผ่าน HTTP (ไม่ควรเปิดไฟล์ตรง ๆ ด้วย `file://`) เพราะเบราว์เซอร์จะไม่ให้ใช้
Geolocation บนโปรโตคอลที่ไม่ปลอดภัย — บนเครื่องตัวเอง `localhost` ถือว่าปลอดภัยแล้ว
ถ้าจะขึ้น production ต้องใช้ HTTPS

## เปิดดูบนมือถือผ่าน GitHub Pages

โปรเจกต์นี้เป็นเว็บสแตติกล้วน จึงวางบน GitHub Pages ได้เลยโดยไม่ต้อง build

1. ไปที่ **Settings → Pages** ของ repo
2. ที่ **Source** เลือก **Deploy from a branch**
3. เลือก branch `main` โฟลเดอร์ `/ (root)` แล้วกด **Save**

รอราว 1-2 นาที เว็บจะขึ้นที่ `https://<ชื่อบัญชี>.github.io/<ชื่อ repo>/`
หลังจากนั้นทุกครั้งที่ push ขึ้น `main` Pages จะอัปเดตให้เองอัตโนมัติ

Pages ให้ HTTPS มาด้วย ระบบติดตามตำแหน่ง (Geolocation) จึงใช้งานได้บนมือถือจริง
บน iPhone กด **แชร์ → เพิ่มไปยังหน้าจอโฮม** จะเปิดแบบเต็มจอเหมือนแอปได้

## โครงสร้างไฟล์

```
index.html          โครงหน้าจอทั้งหมด
tools/serve.ps1     ตัวเสิร์ฟไฟล์สแตติกด้วย PowerShell (สำหรับเครื่องที่ไม่มี Python/Node)
css/style.css       ธีมมืด แผ่นรายการแบบลากได้ และเลย์เอาต์สำหรับหน้าจอ iPhone
js/config.js        ประเภทภัย ระดับความรุนแรง ค่าเริ่มต้นแผนที่ และ URL ของ tile
js/utils.js         คำนวณระยะทาง/ทิศทาง/วงกลม GeoJSON และจัดรูปแบบข้อความ
js/geocode.js       ค้นหาชื่อสถานที่และแปลงพิกัดเป็นชื่อถนน ผ่าน Nominatim
js/route.js         ขอเส้นทางจาก OSRM และแปลงคำสั่งเลี้ยวเป็นภาษาไทย
js/store.js         คลังข้อมูลรายงาน + คะแนนความเสี่ยง + localStorage (pub/sub)
js/risk.js          ความเสี่ยงรายเส้นทาง: จับจุดเสี่ยงเข้ากับถนนที่จะวิ่งผ่าน + โปรไฟล์พาหนะ
js/impact.js        ตัวเลข "อุบัติเหตุลดลงกี่ %" สำหรับกราฟในแดชบอร์ด
js/map.js           แผนที่ 3 มิติ หมุด วงรัศมีเตือน และการควบคุมกล้อง
js/alerts.js        ติดตาม GPS ตรวจภัยข้างหน้า เสียง/เสียงพูด/สั่น และโหมดจำลองการขับ
js/navigate.js      โหมดนำทาง: ความคืบหน้า คำนวณเส้นทางใหม่ และเตือนจุดเสี่ยงบนเส้นทาง
js/ui.js            แผ่นรายการ/รายละเอียด ตัวกรอง ค้นหา ฟอร์มแจ้งเหตุ และ toast
js/app.js           ประกอบทุกส่วนเข้าด้วยกัน
```

การไหลของข้อมูลเป็นทางเดียว: ทุกการเปลี่ยนแปลงเข้า `Store` → `Store` ส่งสัญญาณออก →
`app.js` สั่งให้ `MapView` และ `UI` วาดใหม่ ไม่มีส่วนไหนแก้ DOM ข้ามกันเอง

## ฟีเจอร์

- **แผนที่ 3 มิติ ธีมมืด** — กล้องเอียง อาคารแบบ fill-extrusion ไล่เฉดตามความสูง
  ภูมิประเทศจาก DEM และท้องฟ้า/หมอกระยะไกล สลับเป็นมุมมองดาวเทียมได้
- **แผ่นรายการแบบลากได้** — สามระดับ (แง้ม / ครึ่งจอ / เต็ม) แผนที่ยังเลื่อนได้ตลอดเวลา
  เลือกภัยแล้วเนื้อหาในแผ่นจะสลับเป็นหน้ารายละเอียดพร้อมปุ่มย้อนกลับ
- **สรุปความเสี่ยงรอบตัว** — บอกเป็น "ปลอดภัยกี่ %" คิดจากความรุนแรง ความใกล้
  และคะแนนโหวตของแต่ละจุด และแต่ละจุดในรายการมี % ความเสี่ยงของตัวเองกำกับไว้
- **หน้าค้นหาสถานที่เต็มจอ** — แตะช่องค้นหาบนแผนที่แล้วเปิดเป็นหน้าค้นหาโดยเฉพาะ
  แสดงทั้งจุดเสี่ยงในเครื่องที่ตรงคำค้น และสถานที่จริงจาก Nominatim
- **แผ่นสรุปการเดินทางก่อนออกรถ** — เลือกสถานที่แล้วเลือกว่าไปด้วยรถยนต์หรือมอเตอร์ไซค์
  ระบบจะบอกเวลาเดินทาง ระยะทาง เวลาที่จะถึง และ **ความเสี่ยงเฉพาะถนนที่เส้นทางนั้นวิ่งผ่าน**
  (นับเฉพาะจุดที่อยู่ห่างจากเส้นทางไม่เกิน 120 ม. จึงไม่เอาถนนคู่ขนานมาปน)
- **เปรียบเทียบเส้นทางเพื่อเลี่ยงจุดเสี่ยง** — ขอเส้นทางสำรองจาก OSRM มาให้คะแนนทีละเส้น
  แล้วชี้ว่าเส้นไหนปลอดภัยกว่าและแลกกับเวลาเท่าไร ผู้ใช้เป็นคนเลือกเอง ระบบไม่เปลี่ยนให้เงียบ ๆ
- **เส้นทางระบายสีตามความเสี่ยง** — ช่วงถนนที่มีจุดเสี่ยงจะเปลี่ยนเป็นสีส้ม/แดง
  คล้ายเส้นสีจราจรของ Google Maps แต่ของเราหมายถึง "ช่วงนี้อันตราย" ไม่ใช่ "ช่วงนี้รถติด"
- **ระหว่างนำทาง** — มาตรวัดความเร็ว km/h ป้ายบอกว่าเส้นทางนี้ปลอดภัยแค่ไหน
  และแถบเตือนพร้อมเสียงพูดเมื่อเข้าใกล้จุดเสี่ยงที่อยู่บนเส้นทางข้างหน้า (ภายใน 500 ม.)
- **แถบชิปเลือกประเภท** — ปัดซ้าย-ขวาได้ในตัวเอง กดหนึ่งชิปเพื่อดูเฉพาะประเภทนั้น
  กดซ้ำหรือกด "ทั้งหมด" เพื่อกลับไปดูครบ
- **แผงอัตราการเกิดอุบัติเหตุที่ลดลง** — ตัวเลข % พร้อมกราฟแนวโน้ม 6 เดือนในหน้าแดชบอร์ด
- **หมุดเตือนภัย 9 ประเภท** — อุบัติเหตุ น้ำท่วม ก่อสร้าง หลุมบ่อ สิ่งกีดขวาง รถติด
  ด่านตรวจ ทัศนวิสัยต่ำ สัตว์บนถนน แต่ละจุดมีวงรัศมีเตือนและคลื่นกระเพื่อมเมื่อระดับ "อันตราย"
- **แจ้งเตือนอัตโนมัติ** — เมื่อภัยอยู่ในทิศทางข้างหน้า (±100°) และอยู่ในระยะราว 900 ม.
  จะขึ้นแบนเนอร์ + เสียงเตือน + อ่านออกเสียงภาษาไทย + สั่น (มือถือ) และไม่เตือนซ้ำจุดเดิมภายใน 5 นาที
- **แจ้งเหตุเอง** — เลือกประเภท ระดับความรุนแรง และปักตำแหน่งบนแผนที่ได้
- **โหวตยืนยัน/ปฏิเสธ** และรายงานหมดอายุอัตโนมัติหลัง 12 ชั่วโมง
- **โหมดจำลองการขับ = ฉากสาธิตพร้อมนำเสนอ** — เปิดในหน้าตั้งค่าแล้วระบบจะจัดฉากให้ครบ:
  วางอุบัติเหตุไว้ห่างจากจุดเริ่มราว 500 ม. (เห็นการเตือนภายในไม่กี่วินาที) ตามด้วยกลุ่มรถติด
  และน้ำท่วมบนเส้นทางที่เร็วที่สุด แล้วเปิดแผ่นเปรียบเทียบให้เห็นว่ามีเส้นที่ปลอดภัยกว่าให้เลือก
  จุดสาธิตวางลงบนพิกัดจริงที่ OSRM คืนมา ฉากจึงใช้ได้เสมอ และถูกล้างทิ้งทันทีที่ปิดโหมด
  (ไม่บันทึกลงเครื่องและไม่ปนกับรายงานจริง)

## แหล่งข้อมูลแผนที่

| ชั้นข้อมูล | แหล่ง |
| --- | --- |
| แผนที่เวกเตอร์ + อาคาร | OpenFreeMap (สไตล์ Dark) จาก OpenStreetMap |
| ความสูงภูมิประเทศ | AWS Terrain Tiles (Mapzen terrarium) |
| ภาพดาวเทียม | Esri World Imagery |
| ค้นหาสถานที่ / ชื่อถนน | Nominatim (OpenStreetMap) |

ทั้งหมดเรียกใช้ได้โดยไม่ต้องลงทะเบียน เหมาะกับต้นแบบ แต่ถ้าจะใช้งานจริงที่มีทราฟฟิกสูง
ควรย้ายไปใช้ผู้ให้บริการที่มีข้อตกลงการใช้งานชัดเจน (MapTiler, Mapbox หรือโฮสต์ tile เอง)

Nominatim จำกัดการเรียกไว้ราว 1 ครั้งต่อวินาที แอปจึงหน่วงคำค้นไว้ 650 มิลลิวินาที
และจำผลลัพธ์เดิมไว้ ถ้าจะขึ้น production ควรใช้บริการค้นหาที่รองรับทราฟฟิกสูงกว่านี้

## ข้อจำกัดของต้นแบบนี้

- ข้อมูลเก็บใน `localStorage` ของเบราว์เซอร์เท่านั้น ยังไม่มีการแชร์ระหว่างผู้ใช้จริง
  ขั้นถัดไปคือต่อ backend (เช่น Supabase หรือ Firebase) แล้วเปลี่ยนเฉพาะใน `js/store.js`
- การเตือนแบบ "ภัยรอบตัว" ใช้ระยะเส้นตรงกับทิศทางการเคลื่อนที่ ยังไม่ได้ map-match
  กับเส้นถนนจริง จึงอาจเตือนภัยที่อยู่บนถนนคู่ขนาน (ส่วนการเตือนระหว่างนำทางใช้
  ระยะห่างจากเส้นทางที่ OSRM คืนมา จึงตรงกว่า)
- **กราฟ "อัตราการเกิดอุบัติเหตุที่ลดลง" ในแดชบอร์ดเป็นข้อมูลสาธิต** เพราะรายงานหมดอายุ
  ใน 12 ชั่วโมงและเก็บอยู่ในเครื่องเดียว จึงยังไม่มีสถิติย้อนหลังจริงให้คำนวณ
  หน้าจอกำกับไว้ชัดเจนว่าเป็นตัวอย่าง เมื่อต่อ backend แล้วให้แก้เฉพาะ `js/impact.js`
- ตัวคูณความเสี่ยงของมอเตอร์ไซค์ (1.8 เท่าของรถยนต์) และตัวคูณเวลาเดินทาง (0.85)
  เป็นค่าประมาณเพื่อการเตือน ไม่ใช่ตัวเลขทางสถิติที่อ้างอิงได้ ปรับได้ใน `js/risk.js`
- **เวลาเดินทางเป็นเวลาแบบถนนโล่ง** เพราะ OSRM ไม่มีข้อมูลจราจรสด ในชั่วโมงเร่งด่วน
  ตัวเลขจะต่ำกว่าความจริงมาก และเส้นสีบนเส้นทางบอก "ความเสี่ยง" ไม่ใช่ "รถติด"
- **เส้นทางสำรองไม่ได้มีทุกครั้ง** OSRM จะให้มาเฉพาะเมื่อเจอเส้นที่ต่างกันพอสมควร
  เส้นทางสั้น ๆ ในเมืองมักได้เส้นเดียว ตัวเลือกเปรียบเทียบจึงไม่โผล่
- เส้นทางของมอเตอร์ไซค์ยังไม่ใช่เส้นทางมอเตอร์ไซค์จริง เพราะเซิร์ฟเวอร์ OSRM สาธารณะ
  มีแต่โปรไฟล์รถยนต์ ถ้าจะทำจริงควรย้ายไปใช้บริการที่มีโปรไฟล์มอเตอร์ไซค์ (เช่น GraphHopper)
- อาคาร 3 มิติมีเฉพาะบริเวณที่ OpenStreetMap มีข้อมูลความสูง
